🔒 Политика конфиденциальности

1. Общие положения

LuniMaysOrg (далее — "Компания") уделяет большое внимание защите персональных данных пользователей мессенджера LuniMays (далее — "Сервис").

2. Какие данные мы собираем

  • Адрес электронной почты
  • Имя и username
  • Аватар (по желанию)
  • История сообщений (хранится в зашифрованном виде)
  • Информация о статусе (онлайн/офлайн)

3. Как мы используем данные

  • Для идентификации пользователя
  • Для обеспечения работы мессенджера
  • Для технической поддержки
  • Для улучшения качества сервиса

4. Защита данных

Все данные передаются по защищенному протоколу HTTPS и хранятся в зашифрованном виде. Мы не передаем ваши данные третьим лицам.

5. Ваши права

  • Право на доступ к своим данным
  • Право на исправление данных
  • Право на удаление аккаунта

6. Контакты

По вопросам конфиденциальности: lunimaysorg@gmail.com
